## 📂 Portfolio Projects Directory

### 🔹 [Data Cleaning & Exploration with SQL](./Data%20Cleaning%20with%20SQL)
*   **Core Focus:** Structural Data Cleansing & Advanced Exploratory Data Analysis (EDA)
*   **Tools Used:** MySQL Workbench, Common Table Expressions (CTEs), Analytical Window Functions, Self-Joins
*   **Description:** A complete walkthrough analyzing a messy, real-world global company layoffs dataset. Implemented a rigid multi-phase pipeline that removed duplicate logs using `ROW_NUMBER()`, standardized text string fields, handled structural database missing/null values via automated self-joins, and extracted top historical layoff leaders per year utilizing `DENSE_RANK()`.
